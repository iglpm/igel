# Editor & Tooling Integration

Igel integrates smoothly with modern developer environments, language servers, and continuous integration services through standard JSON message streaming.

## rust-analyzer Integration

You can configure `rust-analyzer` to use `igl check` as its background check runner. This unlocks instantaneous feedback inside your editor while sharing the same content-addressable cache used by your terminal builds:

Add the following configuration to your VS Code `settings.json` or editor configuration:

```json
{
  "rust-analyzer.check.overrideCommand": [
    "igl",
    "check",
    "--message-format=json",
    "--workspace",
    "--all-targets"
  ],
  "rust-analyzer.cargo.buildScripts.overrideCommand": [
    "igl",
    "check",
    "--message-format=json",
    "--workspace",
    "--all-targets"
  ]
}
```

### Why This Works Seamlessly

- **Deterministic Diagnostics**: When compiling or checking with `--message-format=json`, Igel emits Cargo-compatible diagnostic streams (`compiler-message`, `compiler-artifact`, `build-finished`).
- **Cached Diagnostic Replay**: When a crate is restored from the store without recompiling, Igel replays its stored compiler warnings into the JSON stream. Your editor never loses lint warnings simply because an artifact was cached.
- **Build Script Environment**: Igel forwards `build-script-executed` messages (including `OUT_DIR`, environment variables, and `cfg` flags), allowing code generated by build scripts (`include!(concat!(env!("OUT_DIR"), "/bindings.rs"))`) to resolve accurately in your editor.
- **Zero File Lock Conflicts**: Because Igel does not place an exclusive lock on the build directory, background editor checks and terminal builds can run simultaneously without blocking each other.

## Programmatic CLI Interfaces

Igel provides rich machine-readable interfaces for external tooling, dashboards, and IDE extensions:

### Test Suite Results

```bash
igl test --message-format json
```

Streams a structured `test-suite-finished` JSON object for each completed test binary, including execution outcome, pass/fail counters, and individual test timings.

### Build Plan Inspection

```bash
igl graph --units --format json
```

Dumps the complete compilation build plan in JSON format, detailing every compilation unit, its cryptographic cache key, cache hit status, enabled features, target architecture, and upstream dependency edges.
